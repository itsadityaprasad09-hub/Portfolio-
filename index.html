One-time setup (do this once)

  1. Import this repo into Vercel and deploy it.
  2. In the Vercel project → Settings → Environment Variables, add: ANTHROPIC_API_KEY (from console.anthropic.com — separate from claude.ai and billed per token), GITHUB_TOKEN (a repo-scoped PAT for this repo), GITHUB_REPO (e.g. itsadityaprasad09-hub/Portfolio-), and CRON_SECRET (any random string you make up).
  3. Go to cron-job.org (free), create a job that calls https://your-project.vercel.app/api/run?key=YOUR_CRON_SECRET every 5–10 minutes. This is what actually fires prompts on time — Vercel's own free cron only runs once a day.
  4. Come back here, queue a prompt, and it'll show up under Dispatches once it fires.
